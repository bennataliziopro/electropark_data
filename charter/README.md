# Charte RSE — ElectroPark Ontario

Deux pages statiques, sans dépendance autre que Google Fonts :

- `index.html` — CSR Charter (anglais), page d'accueil
- `fr.html` — Charte RSE (français)

Les deux pages se renvoient l'une à l'autre par un lien de langue dans l'en-tête.

## Mise en ligne sur GitHub Pages

1. Créer un dépôt **public**, par exemple `electropark-charter`.
2. Déposer `index.html` et `fr.html` à la racine du dépôt.
3. Dans le dépôt : **Settings → Pages → Source : Deploy from a branch → Branch : main / (root) → Save**.
4. Attendre une à deux minutes. L'URL publiée s'affiche en haut de la même page, sous la forme :
   `https://<utilisateur>.github.io/electropark-charter/`

Transmettre cette URL pour la génération du QR code définitif.
